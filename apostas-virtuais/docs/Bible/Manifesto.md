# Manifesto Evlurn
**v0.8.0-beta | Julho 2026**

---

Não acreditamos que entretenimento e desenvolvimento sejam opostos.

Acreditamos que cada minuto pode gerar algo real — um raciocínio mais ágil, um fato novo, uma habilidade exercitada, uma conquista legítima.

Acreditamos que diversão não precisa ser vazia.

---

**A Evlurn não existe para manter pessoas ocupadas.**

Ela existe para fazer com que cada minuto de entretenimento gere algum tipo de crescimento intelectual, profissional, cultural ou pessoal.

---

Na Evlurn:
- Os jogos não são o destino. São o caminho.
- As conquistas não são enfeites. São registros de evolução.
- O perfil não é uma vitrine. É uma história.
- O conhecimento não é opcional. É o centro.

---

Se você usa a Evlurn por um ano, deve sair diferente de quando entrou.

Mais ágil. Mais curioso. Mais consistente.

Esse é o nosso compromisso.
