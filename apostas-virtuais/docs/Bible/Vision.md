# Vision — O que é a Evlurn?
**v0.8.0-beta | Julho 2026**

---

A Evlurn é uma plataforma de entretenimento inteligente voltada ao desenvolvimento humano.

Um lugar onde jogar e aprender acontecem ao mesmo tempo — sem que um prejudique o outro.

Cada jogo exercita uma habilidade. Cada conteúdo gera recompensa. Cada minuto tem propósito.

---

**Use este documento como filtro para decisões.**

Antes de adicionar qualquer funcionalidade, pergunte:
*"Isso ajuda o usuário a crescer enquanto se diverte?"*

Se não — repense. Se sim — continue.
